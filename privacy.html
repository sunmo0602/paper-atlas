Who this policy covers

This policy covers the app named "paper atlas" shown on Google's sign-in and consent screen, and this website. The app is a private publishing tool used only by the owner of the Paper Atlas YouTube channel. It is not available to the public.

What the app accesses

When the channel owner signs in with Google, the app requests access to the YouTube Data API for the owner's own channel. It uses that access only to:

  • upload videos and thumbnails to the Paper Atlas channel,
  • edit the channel's own video details and publish settings,
  • read comments on the channel's own videos and post replies as the channel,
  • read basic statistics of the channel's own videos.

What the app stores

The app stores the OAuth tokens issued by Google and the YouTube channel ID in a local configuration file on the owner's own computer. Comments and statistics retrieved from the channel are saved locally for the owner's own review. Nothing is stored on any server operated by Paper Atlas.

What the app does not do

  • It does not collect, store or process personal data of viewers or of any Google account other than the channel owner's.
  • It does not sell, share or transfer Google user data to any third party.
  • It does not use Google user data for advertising, profiling, or training of AI models.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The channel owner can revoke the app's access at any time at myaccount.google.com/permissions. Deleting the local configuration file removes the stored tokens. Locally saved comments and statistics can be deleted by removing the files.

This website

This website is a static page hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub may log technical information such as IP addresses as described in GitHub's privacy statement.

Contact

Questions about this policy can be sent through the About page of the Paper Atlas YouTube channel.
